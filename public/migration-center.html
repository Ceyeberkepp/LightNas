Migration Center

Review infrastructure from VMware, Proxmox, TrueNAS or Red Hat. Discovery and planning do not change source systems.

1. Connect to a source

Requires trusted HTTPS certificates and private LAN destinations. Credentials are used for this discovery request and are never saved by the Migration Center.

2. Inventory and compatibility

Alternatively, paste a reviewed inventory manifest as an array of {id, name, type} records. Supported item types: vm, container, storage, network, share, setting, identity.

3. Transfer readiness and verification

No migration running. Discovery and planning only.

Direct source transfer, restore, cutover, and rollback are not implemented yet. Verified local export staging is available. A green compatibility plan is not a successful migration.

Place approved exports in /var/lib/lightnas/imports/incoming using your existing secure transfer method. LightNAS copies and SHA-256 verifies them. Restoration/activation requires a separate verified import step.

Convert VMware / virtual disks

Convert an already staged and verified VMDK, QCOW2 or raw disk into a standalone QCOW2 image. The verified conversion can then be defined as an offline VM.

4. Define a verified VM in LightNAS

Only verified QCOW2/raw disk images are supported. Imported VMs are created powered off; source machines remain unchanged.
